# Vynic releases

Official Vynic Windows downloads and public signed update metadata.

Application source and private signing keys are not stored here. Binary assets belong to immutable GitHub Releases; Render serves `public/` at releases.vynic.ge.

## Current status

The first 1.0.0 beta is being qualified. No installer or update feed is published yet.

## Publication

Publish verified immutable assets first. Publish matching signed versioned repair metadata and latest feeds only after qualification. Never replace an artifact at an already published version. Beta manifest signatures do not provide Windows Authenticode publisher trust.
